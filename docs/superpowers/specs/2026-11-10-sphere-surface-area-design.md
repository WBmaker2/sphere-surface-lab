# 구의 겉넓이($4\pi r^2$) 원리 시각화 인터랙티브 웹앱 설계 문서

- **작성일**: 2026-11-10
- **수업 대상**: 중학교 1학년 2학기 기본도형 및 입체도형 (2022 개정 교육과정)
- **주제**: 구의 겉넓이 공식($S = 4\pi r^2$)의 기하학적 유도 및 시각화
- **기술 스택**: HTML5, Three.js (r128), OrbitControls, Tailwind CSS (CDN), KaTeX (CDN), Web Audio API

---

## 1. 개요 및 설계 목표

### 1.1 학습 목표
1. 구의 겉넓이가 같은 반지름($r$)을 가진 원 4개의 넓이의 합($4 \times \pi r^2 = 4\pi r^2$)과 같다는 원리를 3D 시각화로 직관적으로 이해한다.
2. 구의 표면을 4개의 엽(Quadrant Gore, 귤껍질 형태)으로 분리하여 각 조각이 바닥에 놓인 반지름 $r$인 원 4개를 정확히 1:1로 채우는 과정을 확인한다.
3. 슬라이더로 반지름($r$)과 진행도($0\% \sim 100\%$)를 변경해보며 수학 공식의 수치적·기하학적 일치를 탐구한다.

### 1.2 핵심 사용자 경험
- **무설치 단일 파일**: 다운로드 후 더블클릭만으로 모든 브라우저에서 즉시 실행 (`index.html`).
- **3D 인터랙션**: 마우스 드래그(회전), 우클릭 드래그(팬), 휠(줌)으로 구와 4개 원을 자유롭게 360도 관찰.
- **단계별 연속 모핑 애니메이션**: 버튼 또는 슬라이더로 4개 단계(구 $\to$ 4조각 분리 $\to$ 목표 원 비행 $\to$ 원 채우기)를 끊김 없이 자유자재로 탐색.
- **실시간 공식 유도기**: 반지름 $r$ 변경에 따라 $r$, $\pi r^2$, $4\pi r^2$ 값이 소수점과 함께 즉시 연동.

## 2. 3D 기하 및 애니메이션 수학 알고리즘

### 2.1 4개 구 조각(Quadrant Gores) 모델링
- 구의 반지름을 $r$이라 할 때, 구면 좌표계 $(\rho=r, \theta, \phi)$ 정의:
  - $\phi \in [0, \pi]$ (위도/극각)
  - $\theta \in [0, 2\pi]$ (경도)
- 4개의 조각은 경도 $90^\circ$($\pi/2$) 간격으로 균일 분할:
  - 조각 0: $\theta \in [0, \pi/2]$ (코랄 레드, `#FF6B6B`)
  - 조각 1: $\theta \in [\pi/2, \pi]$ (앰버 골드, `#FFA94D`)
  - 조각 2: $\theta \in [\pi, 3\pi/2]$ (에메랄드 그린, `#51CF66`)
  - 조각 3: $\theta \in [3\pi/2, 2\pi]$ (오션 블루, `#339AF0`)
- 각 조각은 $32 \times 32$ 해상도의 `ParametricGeometry` 또는 커스텀 `BufferGeometry`로 정밀 생성.

### 2.2 바닥 4개 원(Target Disks) 배치
- 높이 $y = -1.5r$ 평면에 4개의 기준 원을 $2 \times 2$ 그리드로 배치:
  - 원 0: $x = -1.6r, z = -1.6r$
  - 원 1: $x = +1.6r, z = -1.6r$
  - 원 2: $x = -1.6r, z = +1.6r$
  - 원 3: $x = +1.6r, z = +1.6r$
- 각 원은 반지름 $r$을 가지며, 반투명 실루엣과 점선 테두리, 그리고 바닥 라벨("원 1: $\pi r^2$" 등)을 가짐.

### 2.3 4단계 모핑 보간 파이프라인 ($t \in [0, 1]$)
애니메이션 진행률 $t$에 따라 버텍스 위치 $P(u, v, t)$를 매끄럽게 계산:

1. **구간 1 ($0.0 \le t \le 0.2$): 온전한 구 상태 및 회전**
   - 4개 조각이 원래 구의 구면 상에 결합되어 있음.
   - 와이어프레임 가이드와 구 중심, 반지름 $r$ 화살표 표시.
2. **구간 2 ($0.2 < t \le 0.45$): 4조각 방사형 분리**
   - 로컬 진행도 $\tau = (t - 0.2) / 0.25$
   - 4개 조각이 각각의 중심 방향 벡터로 방사형으로 $0.5r$만큼 바깥으로 분리됨.
3. **구간 3 ($0.45 < t \le 0.75$): 목표 원 상공으로 비행**
   - 로컬 진행도 $\tau = (t - 0.45) / 0.30$
   - 3차 베지어 곡선 경로를 따라 4개 조각이 바닥 원의 상공($y = -1.5r + 0.3r$)으로 완만한 포물선을 그리며 이동.
   - 조각의 법선 방향이 바닥을 향하도록 점진적 회전 정렬.
4. **구간 4 ($0.75 < t \le 1.0$): 평면화 및 원 채우기 (Flatten & Fit)**
   - 로컬 진행도 $\tau = (t - 0.75) / 0.25$
   - 구면 곡률이 $0$으로 평평해지며, 껍질 조각이 정확히 반지름 $r$인 평면 원판 형태(넓이 $\pi r^2$)로 변형되어 바닥 원에 완전히 결합.
   - 바닥 원판이 선명한 파스텔 톤으로 채워지며 "넓이 = $\pi r^2$" 라벨 강조.

## 4. 상태 관리 및 이벤트 흐름

- **단일 소스 오브 트루스 (Single Source of Truth)**:
  ```javascript
  const state = {
    progress: 0.0,      // 0.0 ~ 1.0 (애니메이션 진행률)
    targetProgress: 0.0,// 부드러운 전환을 위한 목표값
    isPlaying: false,   // 자동 재생 여부
    playbackSpeed: 1.0, // 재생 배속 (0.5x, 1x, 2x)
    radius: 5.0,        // 구 반지름 (1.0 ~ 10.0 cm)
    showOriginalSphere: true, // 원래 구 와이어프레임 가이드
    showSeparationLines: true, // 조각 경계선 표시
    stepIndex: 0        // 0: 관찰, 1: 분리, 2: 이동, 3: 채우기
  };
  ```
- **애니메이션 루프**:
  - `requestAnimationFrame`을 통해 진행도 업데이트 및 보간 처리.
  - 버텍스 셰이더/CPU 버텍스 변환으로 60FPS 부드러운 모핑 유지.
  - 슬라이더 수동 드래그 시 즉각 렌더링 동기화.

## 5. 오류 처리 및 브라우저 호환성

1. **WebGL 지원 확인**: 브라우저에서 WebGL을 지원하지 않는 경우 사용자 친화적 대체 안내 화면 표시.
2. **반응형 뷰포트**: 윈도우 리사이즈 이벤트 발생 시 카메라 종횡비(`aspect`)와 렌더러 크기를 즉시 보정.
3. **터치 제스처 최적화**: 모바일/태블릿 화면에서 OrbitControls와 UI 터치가 충돌하지 않도록 이벤트 버블링 분리.
4. **로컬 오프라인 안정성**: 단일 파일 실행 환경에서 CDN 리소스 로드 실패 시에도 기본 레이아웃과 캔버스가 깨지지 않도록 예외 처리.

## 6. 검증 및 테스트 계획

1. **기하학적 무결성 검증**:
   - $t=0$일 때 4개 조각이 모여 완벽한 구를 형성하는지 확인 (틈새나 겹침 없음).
   - $t=1$일 때 4개 조각이 4개의 바닥 원에 꼭 맞게 안착하는지 확인.
2. **인터랙션 반응성 테스트**:
   - 재생 중 슬라이더를 잡고 역방향으로 드래그할 때 튕김 현상 없이 부드럽게 역재생되는지 확인.
   - 반지름($r$) 슬라이더를 조작했을 때 3D 구와 4개 원, 그리고 계산 패널 수식이 오차 없이 일치하는지 확인.
3. **단일 HTML 구동 확인**:
   - 로컬 파일 시스템(`file:///...`)에서 브라우저로 직접 열었을 때 정상 구동되는지 검증.
